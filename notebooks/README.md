# Notebooks

Esta carpeta debe contener los cuadernos Jupyter del proyecto RiskScore OSCE:

1. `01_carga_datos.ipynb`: carga inicial de datos.
2. `02_limpieza_basica.ipynb`: limpieza básica del dataset.
3. `03_feature_engineering.ipynb`: creación de nuevas features.
4. `04_trainer_model.ipynb`: entrenamiento del modelo.
5. `05_evaluator_model.ipynb`: evaluación del modelo.
6. `06_save_pipeline.ipynb`: guardado del pipeline en `.joblib` y `.pkl`.

Los notebooks completos están incluidos en el paquete ZIP preparado para carga manual o sincronización local con GitHub Desktop.
