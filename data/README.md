# Datos

Esta carpeta documenta los datos usados en el proyecto.

Por tamaño y trazabilidad, se recomienda mantener en GitHub solo datasets procesados de tamaño razonable y excluir los archivos brutos pesados.

## Variable objetivo

`target_sancionado_24m`

- `1`: proveedor con sanción posterior dentro de 24 meses.
- `0`: proveedor sin sanción posterior dentro de 24 meses.

## Fuentes

El proyecto utiliza datos públicos de adjudicaciones y sanciones vinculadas a contratación pública peruana.
